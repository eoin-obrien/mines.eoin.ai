# Mines

Minesweeper for [minesweeper.eoin.ai](https://minesweeper.eoin.ai) — a pure
TypeScript engine with **no-guess board generation**, deterministic seeds, and
replayable games, wrapped in an 8-bit-flavoured single-screen UI.

The interesting part is not the game. It is that every board is a deterministic
function of `(seed, config)`, every game a deterministic function of that board
plus a move log, and that both claims are held up by property tests whose teeth
are measured by mutation testing rather than by line coverage.

> **Status: M0 — scaffold.** The toolchain, CI and coordinate module are in
> place. The playable engine lands over M1–M6; see the milestone table in
> [`SPEC.md`](./SPEC.md).


## Design decisions, briefly

- **Pure TypeScript, not Rust/WASM.** Expert is 480 cells; there is no compute
  problem for WASM to solve, and the WASM boundary would cost the property and
  mutation testing that is the point of the repo. The `Solver` interface stays
  clean so a WASM solver *could* slot in if a benchmark ever justified one.
- **No-guess by default.** Losing a perfect game to a forced 50/50 is the worst
  experience in Minesweeper. Boards are generated by seeded generate-and-test
  with Simon Tatham's perturbation refinement, and verified by a bounded solver.
  A "Classic (guessing allowed)" toggle exists for purists.
- **Deterministic search, so seeds still mean something.** Rejection sampling
  would break the `seed → board` contract; instead the *whole search* is seeded —
  candidate *k* comes from `hash(masterSeed, k)`, and the board is the first *k*
  the solver clears without guessing. Every client computes the same board.
- **Mutation score over coverage.** 100% line coverage proves the code ran.
  Stryker proves the assertions matter; the break threshold is 80, the target 90+.

The long form, with citations, is in [`SPEC.md`](./SPEC.md).

## Testing

```bash
pnpm test           # 100 property runs per property
pnpm test:heavy     # 1000 — what nightly CI runs
pnpm test:coverage  # thresholds enforced at 90%
pnpm mutate         # Stryker
```

Every property test is seeded and prints its seed on failure; reproduce any CI
failure locally with `MINES_PROP_SEED=<seed> pnpm test`.
